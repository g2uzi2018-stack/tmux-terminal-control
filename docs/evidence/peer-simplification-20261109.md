# Peer Coworkers 通用化精简

2026-11-09，WSL，Python 3.12.3，tmux 3.4，Git 2.43.0。

## 交付与取舍

源码和安装版原有 27 个共同文件，其中 11 个不同。源码侧的长报告和审查结论合并到 Markdown 正文，安装侧的完整差异审阅、回复去重和未验收交付保护合并到新版运行时。技能 Python 由安装版的 3,583 行减至 3,291 行，技能说明及参考由约 70 KB 减至约 9 KB。历史模型目录移到证据目录。

工作进程读一份任务说明，提交一份 Markdown。一个状态行区分完成、部分完成、阻塞和提问。删除 READY、任务/尝试/轮次回填、固定结果 JSON、独立长报告和 Cursor 结果发布流程。反馈分配新路径，旧文件原样保留。审查是否完成与审查结论分别写在状态行和正文。实现、研究、审查共享同一流程，工作区写入范围由工作包决定。

保留 CLI sandbox、会话内信任、具体动作的单次审批、首次提交预算、Git 范围校验及独立验收。审批令牌绑定当前卡片的内容，整屏哈希用于记录。关闭会检查当前及尚未被后续收集替代的 DONE，并在结束终端后再核对一次。安装器沿用备份和回滚，用有序相对路径与文件内容计算包指纹。
